# QUBO Problem Dimension per Query

This experiment retrieves the dimension of the QUBO problem (number of qubits) generated by the pipeline for a set of realistic queries.

## Requirements

Activate the conda environment created in the main [README](../README.md):

```bash
conda activate Extended_QA-Prolog
```

**Important:** do not delete the `stdcell.qmasm` file. It is required by the pipeline to generate the QUBO problem correctly.

## Files

- `run_experiment.py` — script version of the experiment.
- `run_experiment.ipynb` — notebook version of the experiment. It is functionally equivalent to the script, but additionally plots the resulting data.

## Running the experiment

```bash
python run_experiment.py
```

Results are saved to `raw_data.tsv`, with one row per query reporting the corresponding number of qubits.
